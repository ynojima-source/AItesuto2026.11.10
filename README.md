# PKキッカー

キッカーとキーパーを交互に務める、ブラウザで遊べるPK戦ゲームです。ゴールの数で勝負します。

## 遊び方

1. [`ゲーム/pk-kicker2.html`](ゲーム/pk-kicker2.html) をブラウザで開く（ダウンロードしてダブルクリックでも動きます）
2. 「スタート」を押す

### 操作（マウス）

| 役割 | 右クリック | 左クリック |
| --- | --- | --- |
| キッカー（蹴る） | 狙う場所を決める | キック |
| キーパー（守る） | 飛ぶ位置を決める | ジャンプ |

- キッカーは、端を狙うほど枠を外しやすくなります。
- キーパーは、青い輪が手の届く範囲です。

## ルール

- 先行・後攻はランダム
- 5回ずつ蹴って、ゴール数が多い方の勝ち
- 同点ならサドンデス
- 1回の制限時間は10秒（時間切れのキックは0点、守りでは動けずに撃たれます）

## 特長

- HTML1ファイルで完結（外部ライブラリ・画像・音声ファイルなし）
- ホイッスル・歓声・ブザーの効果音をWeb Audioで生成
- 得点表で各回の○×と合計を確認できる

## 動作環境

PCのモダンブラウザ（Chrome / Edge / Firefox / Safari）。マウスの左右クリックを使うため、PCでの操作を想定しています。
